# 超星作业答案桥

从作业或考试页面导出答案，在另一个账号的同一份作业/考试里批量填入。

## 安装

需要先装脚本管理器，二选一：

- [Tampermonkey](https://www.tampermonkey.net/)
- [脚本猫 ScriptCat](https://scriptcat.org/)

然后点这个链接安装：

**[安装超星作业答案桥](https://raw.githubusercontent.com/heimenkyou/chaoxing-answer-bridge/main/chaoxing-answer-bridge.user.js)**

脚本管理器会弹出安装确认，点「安装」即可。两个浏览器各装一次。

更新方式相同：再点一次上面的链接，会提示覆盖升级；装好后脚本管理器也会按脚本里的 `@updateURL` 自动检查新版本。

## 使用

1. 答案源账号打开作业详情页（已提交的看答案，没提交的取当前已选的答案）
2. 点脚本管理器图标，选「答案桥：显示 / 隐藏面板」
3. 已提交页点「复制正确答案」或「复制我的答案」；作答页点「复制本页当前作答」
4. 切到目标账号，打开作业作答页，唤出面板，把内容粘贴进去
5. 点「预览匹配」，确认没有标红的题
6. 点「执行填写」
7. 用页面自己的「提交」按钮交卷

面板默认不显示。`×` 或 Esc 收起，下次从脚本管理器菜单重新打开。

### 考试

考试默认是一题一页，脚本不处理这种页面。进入考试后先点页面上的「整卷预览」，变成整卷视图后再按上面的流程操作。

拿另一个账号的考试当答案源时，同样要先在那边点「整卷预览」。已交卷且允许查看答案的考试，页面上会有正确答案；不允许查看就只能在未交卷时导出当前作答。

## 按钮

| 按钮 | 出现位置 | 作用 |
| --- | --- | --- |
| 复制正确答案 | 已提交的作业详情页 | 取正确答案，某题没有正确答案时用该账号自己的作答 |
| 复制我的答案 | 已提交的作业详情页 | 只取该账号自己的作答，不管对错 |
| 复制本页当前作答 | 作答页、整卷预览页 | 导出本页已选中的选项和已填内容，用于没提交时把作答搬到另一个账号 |
| 预览匹配 | 作答页、整卷预览页 | 不修改页面，列出每题的匹配结果与原因 |
| 执行填写 | 作答页、整卷预览页 | 按预览结果写入，写完后重新校验并刷新列表 |

面板下半部分是逐题列表，`✓` 表示取到答案或匹配成功，`!` `?` `×` 分别表示未匹配、本页缺题、出错。点列表里的行会滚动到对应题目。

## 对齐方式

- **题目**：按 `.questionLi[data]` 的题目 id 对齐，两个账号的 id 一致；某题缺 id 时退回归一化后的题干文本
- **客观题**：按选项文本比对，去空白后先精确匹配，再退到去标点、互相包含
- **判断题**：`对 / 正确 / √ / true` 与 `错 / 错误 / × / false` 归一后比较
- **主观题**：按空顺序写入，编辑器里保留 HTML 段落结构，同时回写 `textarea`
- **来源**：已提交页读 `.mark_answer` 里的答案节点；未提交页读当前选中项和各编辑器内容，没作答的题导出为空
- **选中态**：用选项字母上的 `check_answer` / `check_answer_dx` 类名判断，考试页的 `aria-checked` 在切换后会留下旧值，不能作为依据

## 限制

- 分页的作业和考试只处理当前页面已加载的题目
- 考试只支持「整卷预览」视图，逐题视图不处理
- 资料题（材料+多小问）没有在真实页面上验证过
- 不自动提交
